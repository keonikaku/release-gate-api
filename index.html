The ledger is appended by the publish job and lives on the gh-pages branch, not on main. What the platform enforces there is that history cannot be rewritten or deleted: force pushes and branch deletion are refused. It does not stop a person with write access from adding a commit, so the publish job checks the branch history before it appends anything and stops if a commit it did not write is present. Every row carries a run ID that opens GitHub's own record of that run, and a row naming a run GitHub has no record of fails the publish.
